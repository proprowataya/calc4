/*
 * Self-hosted Calc4
 *
 * This program reads a calc4 program from standard input and evaluates it by using calc4 itself.
 * The outer calc4 receives this file as the program.
 * The target calc4 program is passed through standard input.
 *
 * Usage:
 *   $ cat calc4-program.txt | calc4 ./calc4-selfhost.txt
 *
 * To pass input to the target program, put a zero byte after the target source.
 * Bytes after the zero byte are read by the target input operator I.
 *
 * Example:
 *   $ echo 'D[fib|n|n <= 1 ? n ? (n - 1){fib} + (n - 2){fib}] 10{fib}' | calc4 ./calc4-selfhost.txt
 *   55
 *
 * Example with input:
 *   $ { printf 'I + I'; printf '\0'; printf 'AB'; } | calc4 ./calc4-selfhost.txt
 *   131
 *   131 is the sum of A (65) and B (66) in ASCII.
 *
 *   $ { cat ./calc4-selfhost.txt ; printf '\0'; printf 'D[fib|n|n <= 1 ? n ? (n - 1){fib} + (n - 2){fib}] 10{fib}'; } | calc4 ./calc4-selfhost.txt
 *   55
 *   This is a nested self-hosting example.
 *   The inner interpreter reads the Fibonacci program after the zero byte.
 */
